# HenceK Cleaning Service — Website

A modern, fully responsive redesign of the HenceK Cleaning Service website
(residential & commercial cleaning in Houston, TX).

**Tagline:** Sparkling Spaces, Stress-Free Living
**Headline:** Detailed Cleaning You Can See & Feel.

## Stack

Vanilla HTML, CSS and JavaScript — no build step, no dependencies, no external APIs.

## Files

| File | Purpose |
| --- | --- |
| `index.html` | Single-page entry point with semantic sections, meta tags and JSON-LD |
| `styles.css` | Design system (tokens, components, responsive layout) |
| `script.js` | Sticky header, mobile nav, scroll reveal, scroll-spy, mailto quote form |
| `favicon.svg` | Favicon placeholder |

## Running locally

Open `index.html` directly in a browser, or serve the folder:

```bash
python3 -m http.server 8000
# then visit http://localhost:8000
```
